# Titanic Survival Predictor

An end-to-end Machine Learning web application that predicts passenger survival probability on the Titanic, using a **Flask backend** and a **modern ocean-themed frontend**.

## 🚀 Live Demo

- **Frontend:** https://Krithi923.github.io/Titanic_survival_predictor/
- **Backend API:** https://krithi-titanic-api.onrender.com

## 📖 Project Overview

This project demonstrates a complete Machine Learning deployment pipeline:

1. **Train** a Logistic Regression model on the Titanic dataset (Scikit-learn)
2. **Serve** the model via a Flask REST API
3. **Interact** with it through a beautiful frontend with a live probability gauge

## 🧠 Tech Stack

| Layer | Technology |
|---|---|
| ML Model | Scikit-learn (Logistic Regression) |
| Backend | Flask + Flask-CORS |
| Frontend | HTML, CSS, Vanilla JavaScript |
| Deployment | Render (backend) + GitHub Pages (frontend) |

## 📊 Model Details

- **Algorithm:** Logistic Regression
- **Features:** Pclass, Sex, Age, SibSp, Parch
- **Training Accuracy:** 78.51%
- **Testing Accuracy:** 81.56%
- **Dataset:** [Titanic Dataset (891 rows)](https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv)
